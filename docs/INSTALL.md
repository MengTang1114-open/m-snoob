# 安装雪噗噗 Snoob

要求：macOS 14 或更新，Apple 芯片和 Intel 都可以。

1. 到 [Releases](https://github.com/MengTang1114-open/m-snoob/releases/latest) 下载 `Snoob-<版本>.dmg`，双击打开，把 **雪噗噗** 拖进「应用程序」文件夹。
2. 在「应用程序」里双击它。如果这个版本没有 Apple 开发者签名，第一次会提示"无法验证开发者"。这只是因为它没在 Apple 登记，不是有问题。按你的系统版本放行：
   - **macOS 15 及以后**：在提示框里点「完成」。打开「系统设置 → 隐私与安全性」，翻到最下面，点「仍要打开」，输入开机密码，再点「打开」。
   - **macOS 14**：在「应用程序」里右键点雪噗噗，选「打开」，再点「打开」。
3. 如果提示"已损坏，无法打开"：打开「终端」，粘贴下面这行并回车，然后再双击：

   ```
   xattr -dr com.apple.quarantine /Applications/Snoob.app
   ```

只需要放行一次。打开后它住在菜单栏（雪花图标），程序坞里没有它；屏幕右下角会出现一只悬浮的小雪噗噗，点它打开设置。

## 卸载

在面板最下面点「退出雪噗噗」，然后把「应用程序」里的雪噗噗拖进废纸篓。想连设置和计时记录一起清掉，在终端里跑 `defaults delete com.mengtang1114.snoob`。
